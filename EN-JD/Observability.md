# Observability

Focus: Logging, metrics, alerting.

## Key Concepts
- **Logging**: Collect logs (ELK stack, CloudWatch).
- **Metrics**: Monitor performance (Prometheus, Grafana).
- **Alerting**: Notify on issues (PagerDuty, Slack).

## Tools
- Prometheus: Scrape metrics.
- Grafana: Visualize dashboards.
- ELK: Elasticsearch, Logstash, Kibana.

## Real-Time Scenarios
- **Scenario 1**: App slow. Check metrics for CPU/memory.
- **Scenario 2**: Error spike. Query logs for patterns.
- **Scenario 3**: Alert setup. Threshold on response time.
- **Scenario 4**: Incident response. Use dashboards for root cause.
