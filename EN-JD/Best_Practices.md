# Documentation & Best Practices

Focus: Branching, releases, collaboration.

## Key Concepts
- **Branching**: Git flow (feature, develop, main).
- **Releases**: Semantic versioning, changelogs.
- **Documentation**: READMEs, runbooks, APIs.

## Git Flow
- Feature branches for dev.
- PRs for review.
- Main for releases.

## Real-Time Scenarios
- **Scenario 1**: Code review. Use PRs for feedback.
- **Scenario 2**: Release process. Tag versions, deploy.
- **Scenario 3**: Documentation. Update after changes.
- **Scenario 4**: Best practices. Automate linting, testing.
