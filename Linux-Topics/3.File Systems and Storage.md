🟠 Topic 3: File Systems and Storage

This topic covers how Linux stores data, mounts disks, manages capacity, and handles persistent storage. For interviews, be ready with both concepts and the commands used during real troubleshooting.

## 1. File System Types

🔹 Common file systems

`ext4`
general-purpose Linux file system

`xfs`
high-performance file system, common in enterprise Linux

`tmpfs`
memory-based temporary filesystem

🔹 Useful commands

```bash
df -T
lsblk -f
blkid
mount | column -t
```

🔹 Interview questions

What is the difference between `ext4` and `xfs`?
What is `tmpfs` used for?

## 2. Mounting and Unmounting

🔹 Core idea

Linux attaches a filesystem to a directory called a mount point.

🔹 Useful commands

```bash
mount /dev/sdb1 /data
umount /data
findmnt
mount | grep data
```

🔹 Scenario

A new disk is added to the server but the application cannot use it. Check whether the disk is mounted and whether the mount point has correct permissions.

## 3. `/etc/fstab`

🔹 Why it matters

`/etc/fstab` defines persistent mounts across reboot.

🔹 Useful commands

```bash
cat /etc/fstab
mount -a
findmnt --verify
```

🔹 Interview questions

What is `/etc/fstab`?
What happens if there is a wrong entry in `/etc/fstab`?

## 4. Disk Partition Basics

🔹 Core idea

A physical disk can be split into partitions before creating filesystems.

🔹 Useful commands

```bash
lsblk
fdisk -l
parted -l
```

## 5. LVM Basics

🔹 LVM layers

PV: Physical Volume
VG: Volume Group
LV: Logical Volume

🔹 Useful commands

```bash
pvs
vgs
lvs
lvdisplay
vgdisplay
pvdisplay
```

🔹 Scenario

Disk usage is high on `/app`. If it sits on LVM, check whether the volume group has free space to extend the logical volume.

## 6. Swap Management

🔹 Core idea

Swap is disk space used when RAM pressure increases.

🔹 Useful commands

```bash
free -h
swapon --show
cat /proc/swaps
vmstat 1 5
```

🔹 Interview questions

What is swap?
Can a Linux system run without swap?

## 7. Disk Usage Analysis

🔹 Most-used commands

```bash
df -h
du -sh /var/*
du -xhd1 /
lsblk
find / -xdev -type f -size +500M 2>/dev/null
```

🔹 Scenario

The root filesystem is 100% full. Start with `df -h`, then use `du` on large directories, and finally search for oversized files.

## 8. Inode Concept

🔹 Core idea

An inode stores metadata about a file. A filesystem can run out of inodes even if free space remains.

🔹 Useful commands

```bash
df -i
ls -i
stat file.txt
```

🔹 Interview questions

What is an inode?
What is the difference between disk full and inode full?

## 9. ACL Basics

🔹 Why it matters

ACLs provide more granular permissions than standard user/group/others permissions.

🔹 Useful commands

```bash
getfacl file.txt
setfacl -m u:appuser:rwx file.txt
setfacl -x u:appuser file.txt
```

## 🔥 Real Interview Scenarios

Scenario 1:
Filesystem is full.

Check:

```bash
df -h
du -sh /*
find / -xdev -type f -size +1G 2>/dev/null
```

Scenario 2:
Mount is missing after reboot.

Check:

```bash
cat /etc/fstab
mount -a
journalctl -b | grep -i mount
```

Scenario 3:
Space is free but new files cannot be created.

Check inode exhaustion:

```bash
df -i
```

✅ Summary

For 4 years experience, be comfortable with `df`, `du`, `lsblk`, `mount`, `fstab`, LVM basics, and inode troubleshooting.
