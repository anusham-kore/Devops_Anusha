# Security Topics

Linux security is a must-know interview area. You do not need to be a security specialist, but you should understand permissions, access control, SSH hardening, and basic system protection.

## 1. Linux Permission Model

### Key concepts

owner
group
others
read
write
execute

## 2. `chmod`, `chown`, `umask`

### Useful commands

```bash
chmod 644 file.txt
chmod 755 script.sh
chown appuser:devops file.txt
umask
umask 022
```

## 3. SUID, SGID, Sticky Bit

### Useful commands

```bash
find / -perm -4000 2>/dev/null
find / -perm -2000 2>/dev/null
find /tmp -maxdepth 0 -ls
chmod +t /shared
```

## 4. SSH Hardening Basics

### Common improvements

Disable direct root login
Prefer key-based auth
Disable unused auth methods
Limit users if needed

### Useful commands

```bash
grep -Ei "permitrootlogin|passwordauthentication|allowusers" /etc/ssh/sshd_config
sshd -t
systemctl restart sshd
```

## 5. Firewall Management Basics

### Useful commands

```bash
firewall-cmd --list-all
firewall-cmd --add-port=8080/tcp --permanent
firewall-cmd --reload
iptables -L -n
```

## 6. SELinux or AppArmor Basics

### Useful commands

```bash
getenforce
sestatus
ls -Z /var/www/html
```

## 7. File Integrity and Access Awareness

### Core idea

Track who can access sensitive files and keep permission scopes minimal.

## 8. Basic Hardening Practices

### Examples

Remove unused packages
disable unused services
restrict root access
apply patches
use least privilege

##  Real Interview Scenarios

Scenario 1:
Application gets permission denied on a file.

Check:

```bash
ls -l file
ls -Z file
id appuser
```

Scenario 2:
SSH works for key auth users but not password users.

Check `PasswordAuthentication` in `sshd_config`.

Scenario 3:
Port is open in app config but inaccessible externally.

Check service bind, firewall, and SELinux context if applicable.

## Summary

Focus on permissions, ownership, SSH security, firewall basics, and SELinux awareness.
