🟡 Topic 2: Command Line Mastery

This topic is one of the most important parts of Linux interview preparation. For a 4 years experience profile, interviewers expect strong command-line comfort because real troubleshooting, log analysis, file operations, and admin work are mostly done from the terminal.

1. Navigation Commands

🔹 What it means

Navigation commands help you move through the Linux file system and understand your current location.

🔹 Important commands

```bash
pwd
ls
ls -l
ls -a
cd /etc
cd ..
cd ~
cd -
```

🔹 Interview point

`pwd` shows the present working directory. `cd` changes the current directory. `ls` lists directory contents.

🔹 Scenario

If you are troubleshooting a service configuration and need to switch between `/etc`, `/var/log`, and your home directory quickly, commands like `cd -`, `cd ..`, and `pwd` help navigate efficiently.

🔹 Common interview questions

How do you check your current directory?
What is the difference between `cd ~` and `cd -`?
How do you list hidden files?

2. File and Directory Operations

🔹 What it means

These commands are used for creating, copying, moving, deleting, and viewing files and directories.

🔹 Important commands

```bash
touch file.txt
mkdir demo
mkdir -p app/logs/archive
cp file.txt backup.txt
cp -r dir1 dir2
mv old.txt new.txt
rm file.txt
rm -r demo
rmdir emptydir
cat file.txt
less file.txt
head -10 file.txt
tail -10 file.txt
tail -f /var/log/messages
```

🔹 Interview point

`cp` copies files, `mv` moves or renames files, and `rm` removes files. `tail -f` is widely used for real-time log monitoring.

🔹 Scenario

During a deployment issue, you may need to back up a config file before editing it:

```bash
cp /etc/nginx/nginx.conf /etc/nginx/nginx.conf.bak
```

🔹 Common interview questions

How do you copy a directory recursively?
What is the difference between `rm -r` and `rmdir`?
How do you monitor a log file in real time?

3. Searching with `find`, `locate`, `grep`

🔹 What it means

These commands help search files, directories, and content.

🔹 Important commands

```bash
find /var/log -name "*.log"
find / -type f -name "httpd.conf" 2>/dev/null
find /tmp -mtime -1
find . -size +100M
locate sshd_config
grep "error" app.log
grep -i "failed" /var/log/secure
grep -r "Listen 80" /etc/httpd
grep -n "root" /etc/passwd
```

🔹 Interview point

`find` searches the filesystem in real time. `locate` is faster because it uses a database. `grep` searches inside files for matching text.

🔹 Scenario

If you need to find all files modified today in a log directory, use `find` with time-based filters. If a service is failing and you need to search for `error` lines in logs, use `grep`.

🔹 Common interview questions

What is the difference between `find` and `locate`?
How do you search for a string in multiple files?
How do you search case-insensitively using `grep`?

4. Text Processing with `cut`, `awk`, `sed`, `sort`, `uniq`

🔹 What it means

Text processing commands are used heavily in Linux admin work for parsing logs, reports, command output, and config files.

🔹 Important commands

```bash
cut -d: -f1 /etc/passwd
awk '{print $1}' file.txt
awk -F: '{print $1,$7}' /etc/passwd
sed 's/error/ERROR/g' app.log
sed -n '1,10p' file.txt
sort names.txt
sort -n numbers.txt
uniq names.txt
sort names.txt | uniq
sort names.txt | uniq -c
```

🔹 Interview point

`cut` extracts fields, `awk` is used for pattern scanning and reporting, `sed` is used for stream editing, `sort` arranges data, and `uniq` removes adjacent duplicates.

🔹 Scenario

If an interviewer asks how to display only usernames from `/etc/passwd`, a practical answer is:

```bash
cut -d: -f1 /etc/passwd
```

Or using `awk`:

```bash
awk -F: '{print $1}' /etc/passwd
```

🔹 Common interview questions

What does `awk -F:` mean?
Why is `uniq` often used with `sort`?
How do you replace text in a file using `sed`?

5. Archiving and Compression with `tar`, `gzip`, `zip`

🔹 What it means

These commands are used to package files for backup, transfer, and storage optimization.

🔹 Important commands

```bash
tar -cvf backup.tar /etc
tar -xvf backup.tar
tar -czvf backup.tar.gz /var/log
tar -xzvf backup.tar.gz
gzip file.txt
gunzip file.txt.gz
zip -r project.zip project/
unzip project.zip
```

🔹 Interview point

`tar` creates or extracts archives. `gzip` compresses files. `tar -czvf` both archives and compresses content into a `.tar.gz` file.

🔹 Scenario

Before making changes to a production configuration directory, you might take a quick backup:

```bash
tar -czvf etc-backup.tar.gz /etc
```

🔹 Common interview questions

What is the difference between archiving and compression?
How do you extract a `.tar.gz` file?
How do you create a backup archive of a directory?

6. Redirection and Pipes

🔹 What it means

Redirection and pipes are used to control input and output flow between commands and files.

🔹 Important operators

`>`
overwrite output to a file

`>>`
append output to a file

`2>`
redirect standard error

`|`
pass output from one command to another

🔹 Important commands

```bash
ls > files.txt
echo "done" >> result.log
find / -name test 2>/dev/null
ps -ef | grep nginx
cat /etc/passwd | wc -l
df -h | grep "/dev"
```

🔹 Interview point

Pipes connect commands, while redirection stores output or errors in files.

🔹 Scenario

If you want to ignore permission errors while searching the filesystem, redirect standard error:

```bash
find / -name "*.conf" 2>/dev/null
```

🔹 Common interview questions

What is the difference between `>` and `>>`?
What does `2>/dev/null` do?
How do pipes help in Linux?

7. Command Substitution

🔹 What it means

Command substitution allows the output of one command to be used as an argument to another command.

🔹 Important syntax

```bash
echo $(date)
files=$(ls /etc | wc -l)
echo $files
```

🔹 Interview point

`$(command)` is the modern and readable way to capture command output.

🔹 Scenario

In scripting, command substitution is often used to store values like hostname, date, process counts, and disk usage into variables.

🔹 Common interview questions

What is command substitution?
What is the difference between backticks and `$( )`?

8. Working with `history`

🔹 What it means

The history command stores previously executed commands and helps improve speed and troubleshooting.

🔹 Important commands

```bash
history
history | grep ssh
!100
!!
!grep
```

🔹 Interview point

`history` helps reuse previous commands quickly. `!!` reruns the last command.

🔹 Scenario

If you ran a long command incorrectly and want to fix it quickly, command history reduces time and typing effort.

🔹 Common interview questions

How do you search command history?
How do you rerun the previous command?

9. Aliases and Shell Customization

🔹 What it means

Aliases and shell customization help make repetitive commands shorter and improve user productivity.

🔹 Important commands

```bash
alias ll='ls -ltr'
alias gs='git status'
alias
unalias ll
```

🔹 Permanent alias setup

Add aliases in:

`~/.bashrc`
`~/.bash_profile`

Then reload:

```bash
source ~/.bashrc
```

🔹 Interview point

Aliases are shortcuts for commands. They improve productivity but should be used carefully in scripts because aliases are mainly interactive shell features.

🔹 Scenario

If you check logs and directory listings regularly, aliases can save time during daily administration.

🔹 Common interview questions

What is an alias?
How do you make an alias permanent?
Why should aliases be avoided in scripts?
