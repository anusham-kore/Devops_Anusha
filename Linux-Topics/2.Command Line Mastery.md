# Command Line Mastery

This topic covers the Linux command-line skills expected in interviews and real troubleshooting work. For a 4-year experience profile, interviewers expect you to be comfortable with navigation, file operations, searching, log reading, text processing, pipes, and quick command combinations.

## 1. Navigation Commands

Navigation commands help you move through the Linux file system and understand your current location.

### Useful commands
```bash
pwd
ls
ls -l
ls -a
cd /etc
cd ..
cd ~
cd -
```

### Why this matters
- `pwd` shows the present working directory
- `ls` lists files and directories
- `cd` changes the current directory
- `cd -` quickly returns to the previous directory

### Scenario
If you are troubleshooting a service configuration and need to switch between `/etc`, `/var/log`, and your home directory, commands like `cd -`, `cd ..`, and `pwd` help you move quickly without losing context.

## 2. File and Directory Operations

These commands are used to create, copy, move, delete, and view files and directories.

### Useful commands
```bash
touch file.txt
mkdir demo
mkdir -p app/logs/archive
cp file.txt backup.txt
cp -r dir1 dir2
mv old.txt new.txt
rm file.txt
rm -r demo
rmdir emptydir
cat file.txt
less file.txt
head -10 file.txt
tail -10 file.txt
tail -f /var/log/messages
```

### Why this matters
- `cp` copies files or directories
- `mv` moves or renames files
- `rm` removes files
- `tail -f` is commonly used for real-time log monitoring

### Scenario
Before editing a production configuration file, take a backup:

```bash
cp /etc/nginx/nginx.conf /etc/nginx/nginx.conf.bak
```

## 3. Searching with `find`, `locate`, and `grep`

Search commands help you find files, directories, and text inside files.

### Useful commands
```bash
find /var/log -name "*.log"
find / -type f -name "httpd.conf" 2>/dev/null
find /tmp -mtime -1
find . -size +100M
locate sshd_config
grep "error" app.log
grep -i "failed" /var/log/secure
grep -r "Listen 80" /etc/httpd
grep -n "root" /etc/passwd
```

### Why this matters
- `find` searches the filesystem in real time
- `locate` is faster because it uses a database
- `grep` searches inside files for matching text
- `2>/dev/null` hides permission errors while searching

### Scenario
If a service is failing and you need to search for error messages, use:

```bash
grep -i "error" /var/log/messages
```

If disk space is full and you need to find large files, use:

```bash
find / -type f -size +500M 2>/dev/null
```

## 4. Text Processing with `cut`, `awk`, `sed`, `sort`, and `uniq`

Text processing commands are heavily used for parsing logs, reports, command output, and configuration files.

### Useful commands
```bash
cut -d: -f1 /etc/passwd
awk '{print $1}' file.txt
awk -F: '{print $1,$7}' /etc/passwd
sed 's/error/ERROR/g' app.log
sed -n '1,10p' file.txt
sort names.txt
sort -n numbers.txt
uniq names.txt
sort names.txt | uniq
sort names.txt | uniq -c
```

### Why this matters
- `cut` extracts fields
- `awk` is useful for pattern scanning and reporting
- `sed` edits text streams
- `sort` arranges output
- `uniq` removes adjacent duplicate lines, so it is often used after `sort`

### Scenario
To display only usernames from `/etc/passwd`, use:

```bash
cut -d: -f1 /etc/passwd
```

Or:

```bash
awk -F: '{print $1}' /etc/passwd
```

## 5. Archiving and Compression

Archiving groups files together. Compression reduces file size. These are commonly used for backups, transfers, and log collection.

### Useful commands
```bash
tar -cvf backup.tar /etc
tar -xvf backup.tar
tar -czvf backup.tar.gz /var/log
tar -xzvf backup.tar.gz
gzip file.txt
gunzip file.txt.gz
zip -r project.zip project/
unzip project.zip
```

### Why this matters
- `tar` creates or extracts archives
- `gzip` compresses a file
- `tar -czvf` creates a compressed `.tar.gz` archive

### Scenario
Before changing a configuration directory, take a quick backup:

```bash
tar -czvf etc-backup.tar.gz /etc
```

## 6. Redirection and Pipes

Redirection and pipes control command input and output.

### Common operators
| Operator | Meaning |
| --- | --- |
| `>` | Write output to a file and overwrite existing content |
| `>>` | Append output to a file |
| `2>` | Redirect standard error |
| `|` | Pass output from one command to another |

### Useful commands
```bash
ls > files.txt
date >> activity.log
find / -name app.conf 2>/dev/null
cat app.log | grep ERROR
ps aux | grep nginx
```

### Why this matters
Pipes let you combine simple commands into powerful troubleshooting commands. For example, you can list processes and filter only the service you care about.

## 7. Command Substitution

Command substitution uses the output of one command inside another command.

### Useful examples
```bash
echo "Today is $(date)"
cp app.log app-$(date +%F).log
mkdir backup-$(date +%F)
```

### Why this matters
It is useful in scripts, backups, logs, and automation where filenames or values need to be generated dynamically.

## 8. History and Shell Productivity

The shell keeps command history and supports shortcuts that make daily work faster.

### Useful commands
```bash
history
history | grep systemctl
!100
!!
alias ll='ls -lah'
unalias ll
```

### Why this matters
- `history` helps you reuse previous commands
- `!!` repeats the last command
- Aliases save time for repeated command patterns

### Scenario
If you previously restarted a service and want to find the exact command again, use:

```bash
history | grep systemctl
```

## Common Interview Questions

- How do you check your current directory?
  Answer:
  Use `pwd`. It prints the present working directory.

- What is the difference between `cd ~` and `cd -`?
  Answer:
  `cd ~` takes you to the current user's home directory. `cd -` takes you back to the previous directory.

- How do you list hidden files?
  Answer:
  Use `ls -a`. Hidden files in Linux usually start with a dot, such as `.bashrc`.

- How do you copy a directory recursively?
  Answer:
  Use `cp -r source_directory destination_directory`.

- What is the difference between `rm -r` and `rmdir`?
  Answer:
  `rm -r` removes a directory and its contents recursively. `rmdir` removes only an empty directory.

- How do you monitor a log file in real time?
  Answer:
  Use `tail -f /path/to/logfile`. For example, `tail -f /var/log/messages`.

- What is the difference between `find` and `locate`?
  Answer:
  `find` searches the live filesystem and supports many filters. `locate` is faster because it searches a prebuilt database, but it may not show very recent files until the database is updated.

- How do you search for a string in multiple files?
  Answer:
  Use `grep -r "search_text" /path`. The `-r` option searches recursively.

- What does `awk -F:` mean?
  Answer:
  `-F:` tells `awk` to use colon as the field separator. This is useful for files like `/etc/passwd`.

- Why is `uniq` often used with `sort`?
  Answer:
  `uniq` removes only adjacent duplicate lines. Sorting first brings duplicate lines together.

- How do you replace text using `sed`?
  Answer:
  Use a substitution command such as `sed 's/old/new/g' file.txt`. The `g` means replace all matches on each line.

## Final Tip

Do not study commands as isolated syntax. Practice combining them for real tasks, such as finding large files, checking logs, taking backups, and filtering service output. That is what interviewers usually care about.
