🟣 Topic 5: Process Management

Process management is central to Linux operations. Interviewers expect you to know how to inspect, control, prioritize, and troubleshoot processes.

## 1. Process Lifecycle

🔹 Core concepts

PID
PPID
foreground
background
daemon
zombie

## 2. Inspecting Processes

🔹 Useful commands

```bash
ps -ef
ps aux
top
pgrep nginx
pidof sshd
pstree -p
```

## 3. Killing Processes

🔹 Useful commands

```bash
kill 1234
kill -9 1234
pkill nginx
killall java
```

🔹 Interview point

Use normal termination first. `kill -9` is forceful and should be used carefully.

## 4. Foreground and Background Jobs

🔹 Useful commands

```bash
jobs
bg
fg
nohup ./script.sh &
disown
```

## 5. Nice and Renice

🔹 Core idea

Niceness affects CPU scheduling priority.

🔹 Useful commands

```bash
nice -n 10 ./script.sh
ps -eo pid,ni,cmd
renice 5 -p 1234
```

## 6. Service Troubleshooting Basics

🔹 Useful commands

```bash
systemctl status nginx
journalctl -u nginx
ss -lntp
lsof -p 1234
```

## 🔥 Real Interview Scenarios

Scenario 1:
One process is consuming high CPU.

Check:

```bash
top
ps -eo pid,ppid,%cpu,%mem,cmd --sort=-%cpu | head
```

Scenario 2:
Application is stuck after logout.

Use `nohup` or a service manager such as `systemd`.

Scenario 3:
Process will not stop.

Try:

```bash
kill <pid>
kill -15 <pid>
kill -9 <pid>
```

✅ Summary

Be strong with `ps`, `top`, `pgrep`, `kill`, job control, and CPU priority concepts.
