🔵 Topic 4: User and Access Management

This topic focuses on how Linux controls identity, authentication, and privilege. It is one of the most common interview areas because it directly affects security and daily administration.

## 1. User Creation and Modification

🔹 Useful commands

```bash
useradd appuser
passwd appuser
usermod -aG wheel appuser
userdel appuser
id appuser
```

🔹 Interview questions

How do you create a user?
How do you add a user to a group?

## 2. Group Management

🔹 Useful commands

```bash
groupadd devops
groupmod -n platform devops
groupdel platform
groups appuser
getent group
```

## 3. Password Policies

🔹 Core idea

Linux can enforce password aging, expiry, and complexity through PAM and account policy settings.

🔹 Useful commands

```bash
chage -l appuser
chage -M 90 appuser
passwd -l appuser
passwd -u appuser
```

## 4. `sudo` Configuration

🔹 Useful commands

```bash
visudo
sudo -l
sudo -u appuser whoami
cat /etc/sudoers
ls /etc/sudoers.d
```

🔹 Interview questions

Why use `visudo` instead of editing `/etc/sudoers` directly?
How do you grant limited sudo access?

## 5. Account Locking and Expiry

🔹 Useful commands

```bash
passwd -l appuser
passwd -S appuser
chage -E 2026-12-31 appuser
faillog -a
```

## 6. PAM Basics

🔹 Core idea

PAM controls authentication, account rules, password policy, and session behavior.

🔹 Important paths

`/etc/pam.d/`
`/etc/security/`

## 7. SSH Configuration

🔹 Important paths

`/etc/ssh/sshd_config`
`~/.ssh/authorized_keys`

🔹 Useful commands

```bash
sshd -t
systemctl status sshd
grep -Ei "permitrootlogin|passwordauthentication" /etc/ssh/sshd_config
```

## 8. Key-Based Authentication

🔹 Useful commands

```bash
ssh-keygen
ssh-copy-id user@server
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
```

## 🔥 Real Interview Scenarios

Scenario 1:
User cannot run sudo.

Check:

```bash
sudo -l
id username
visudo
ls /etc/sudoers.d
```

Scenario 2:
SSH login is failing.

Check:

```bash
systemctl status sshd
sshd -t
journalctl -u sshd
ls -ld ~/.ssh
ls -l ~/.ssh/authorized_keys
```

Scenario 3:
User account must expire automatically.

Use:

```bash
chage -E 2026-12-31 username
```

✅ Summary

Know user/group commands, `sudo`, SSH access, password aging, and the basics of PAM. These are core Linux admin expectations.
