# Incident Troubleshooting

Focus: Response, resolution.

## Key Concepts
- **Process**: Identify, contain, eradicate, recover, learn.
- **Tools**: Logs, metrics, runbooks.

## Steps
1. Alert received.
2. Assess impact.
3. Gather data (logs, metrics).
4. Isolate cause.
5. Implement fix.
6. Monitor recovery.
7. Post-mortem.

## Real-Time Scenarios
- **Scenario 1**: Service down. Check pod status, restart if needed.
- **Scenario 2**: Data loss. Restore from backup.
- **Scenario 3**: Security breach. Isolate affected systems.
- **Scenario 4**: Performance issue. Scale resources, optimize code.
