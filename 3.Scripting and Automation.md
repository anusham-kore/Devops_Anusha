# Scripting and Automation

This file covers the scripting and automation basics that are important for Azure administration, DevOps work, and interview preparation. These topics help you reduce manual effort, improve consistency, and handle repetitive operational tasks more efficiently.

## 1. Why Scripting Matters

Scripting allows you to automate repeated tasks instead of doing them manually each time.

### Common benefits
- Saves time
- Reduces human error
- Improves consistency
- Helps with bulk operations
- Makes troubleshooting and deployment faster

### Common real-world use cases
- Creating users or resources in bulk
- Restarting services automatically
- Checking server health
- Parsing logs
- Deploying infrastructure or applications

## 2. PowerShell Basics

PowerShell is widely used in Windows administration, Azure operations, and automation.

### What PowerShell is
- A command-line shell and scripting language
- Object-based, not plain text-based like many traditional shells
- Commonly used for Windows and Azure administration

### Basic concepts
- Commands are called cmdlets
- Cmdlets usually follow a `Verb-Noun` format
- Example: `Get-Service`, `Restart-Service`, `Get-Process`

### Useful PowerShell commands
- `Get-ChildItem` lists files and folders
- `Get-Service` lists services
- `Get-Process` lists running processes
- `Set-Location` changes directories
- `Get-Content` reads file content

### Why PowerShell matters
- Azure PowerShell is commonly used in enterprise environments
- It is very useful for administration and automation on Windows systems

## 3. Bash Basics

Bash is a common shell in Linux systems and is widely used in servers, DevOps pipelines, and cloud environments.

### What Bash is
- A command-line shell used in Linux and Unix-like systems
- Commonly used for automation, scripting, and system administration

### Useful Bash commands
- `pwd` shows the current directory
- `ls` lists files
- `cd` changes directories
- `cat` displays file contents
- `grep` searches text
- `chmod` changes permissions

### Why Bash matters
- Many cloud and container-based workloads run on Linux
- DevOps engineers frequently use Bash in CI/CD pipelines and automation scripts

## 4. Variables, Loops, Conditions, and Functions

These are basic building blocks of scripts.

### Variables
- Variables store values for reuse
- Example uses:
  storing a file path, server name, username, or environment name

### Loops
- Loops repeat actions
- Example:
  restarting multiple servers one by one from a list

### Conditions
- Conditions help scripts make decisions
- Example:
  if a file exists, continue; otherwise show an error

### Functions
- Functions group reusable logic
- Example:
  creating one function to check service health and reusing it across scripts

### Why these matter
- They help convert one-time commands into reusable automation

## 5. Writing Small Automation Scripts

A good beginner script solves one clear problem and is easy to understand.

### Examples of simple scripts
- Check whether a service is running
- Create folders for a deployment
- Back up log files
- Monitor disk usage
- Validate whether a website is reachable

### Good scripting habits
- Use meaningful variable names
- Add simple error handling
- Print useful output messages
- Keep the script focused on one task
- Test with safe sample data first

## 6. Basic JSON and YAML Understanding

JSON and YAML are common data formats used in cloud, DevOps, and configuration files.

### JSON
- Stands for JavaScript Object Notation
- Uses key-value pairs
- Commonly used in APIs, Azure templates, and configuration data

### Example JSON
```json
{
  "environment": "dev",
  "location": "eastus"
}
```

### YAML
- A human-readable data format
- Commonly used in CI/CD pipelines and configuration files

### Example YAML
```yaml
environment: dev
location: eastus
```

### Why they matter
- Azure, DevOps, and automation tools often use JSON and YAML
- Interviewers may ask where each format is commonly used

## 7. Automation in DevOps and Cloud

Automation is a core part of DevOps practice.

### Where automation is used
- CI/CD pipelines
- Infrastructure deployment
- Monitoring and alerts
- Backup and cleanup jobs
- User and permission management

### Why it matters
- Manual work does not scale well
- Automation improves repeatability and reliability

## 8. Common Scripting Mistakes

Beginners often make a few common mistakes that interviewers may indirectly test through scenario questions.

### Common mistakes
- Hardcoding values that should be variables
- Not handling failures or missing files
- Running scripts without testing
- Not checking permissions before performing actions
- Writing scripts that are too large and hard to maintain

### Interview point
- Good automation is not only about making tasks automatic, but also about making them safe and reliable

## Common Interview Questions

- Why is scripting important in DevOps and cloud work?
  Answer:
  Scripting is important because it automates repetitive tasks, reduces manual errors, and improves consistency. In cloud and DevOps environments, manual work does not scale well, so scripting helps teams operate faster and more reliably.

- What is the difference between PowerShell and Bash?
  Answer:
  PowerShell is an object-based shell commonly used in Windows and Azure environments, while Bash is a text-based shell commonly used in Linux and Unix systems. Both are useful for automation, but they are most common in different administration environments.

- What are variables in scripting?
  Answer:
  Variables store values that a script can reuse, such as file paths, usernames, or server names. They make scripts easier to update and maintain because you do not need to repeat hardcoded values.

- Why do we use loops in scripts?
  Answer:
  Loops are used to repeat actions without writing the same code again and again. For example, a loop can restart multiple services or create several user accounts from a list.

- What is the purpose of conditions in a script?
  Answer:
  Conditions allow a script to make decisions based on a situation. For example, a script can check whether a file exists before trying to read it.

- What is JSON and where is it used?
  Answer:
  JSON is a structured data format that uses key-value pairs. It is commonly used in APIs, configuration files, and infrastructure templates such as ARM-based deployments.

- What is YAML and where is it used?
  Answer:
  YAML is a human-readable configuration format commonly used in CI/CD pipelines, Kubernetes manifests, and application settings. It is popular because it is easier to read and write than some other structured formats.

- What makes a good automation script?
  Answer:
  A good automation script is simple, readable, reusable, and safe. It should use clear variable names, handle errors properly, avoid unnecessary hardcoding, and solve one well-defined problem.

- What are common scripting mistakes?
  Answer:
  Common mistakes include hardcoding values, not handling errors, skipping testing, and writing overly complex scripts. These issues can cause failures and make automation difficult to trust.

## Final Tip

Do not try to memorize scripting only as syntax. Practice writing small scripts for real tasks like checking services, reading files, or automating simple admin work.

That practical habit helps a lot in interviews because you can explain both the concept and how you actually use it.
